
# SalesPulse BI — Interactive Sales Analytics Dashboard

An interactive sales analytics dashboard built to help users explore sales data, monitor business performance, and uncover actionable insights.

Developed as a capstone project for the **AI Agent for Data Analysis** learning track in the **Hacktiv8 × IBM SkillsBuild** program.

## Overview

SalesPulse BI aims to make sales data easier to understand through interactive visualizations and key performance indicators (KPIs). Users can explore sales performance and identify patterns that may support data-informed business decisions.

## Key Features

- **Sales Performance Monitoring** — Track relevant sales metrics and performance indicators.
- **Interactive Data Visualization** — Explore sales trends and comparisons through charts.
- **Data Import** — Intended to support analysis of user-provided sales datasets, subject to the implemented file formats.
- **Business Insights** — Explore sales patterns across available categories and dimensions.
- **Export and Reporting** — Use supported export features to continue analysis outside the dashboard.

*The final feature list should reflect the functionality implemented in the current version.*
