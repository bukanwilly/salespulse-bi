🔒 Your file is processed entirely in your browser. Nothing is uploaded to any server. About this dashboard
▲ What This Dashboard Does
  • Auto-detects column types from your file
  • Maps columns to revenue, quantity, date, region, category, and more
  • Validates data quality before generating analytics
  • Computes KPIs with documented formulas
  • Generates concise, evidence-based executive insights
  • Provides actionable recommendations
■ Technologies Used
  • HTML5 · CSS (custom) · Vanilla JavaScript
  • Chart.js 4 for visualisations
  • PapaParse for robust CSV parsing
  • SheetJS (XLSX) for Excel support
  • 100% client-side — no backend, no server
ⓘ Privacy
  • Files never leave your browser
  • No data sent to any server
  • No analytics or tracking on your data
  • Clear Data button removes all data from session
  • Safe to use with business data
◆ Supported Columns
  • Revenue / Sales / Amount / Total
  • Date / Order Date / Transaction Date
  • Quantity / Qty / Units Sold
  • Discount / Discount Rate / Discount %
  • Region / Territory / Area
  • Category / Product / Salesperson / Channel
